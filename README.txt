نسخة GitHub جاهزة للتجربة

1) ارفع index.html إلى مستودع GitHub.
2) فعّل GitHub Pages.
3) افتح الموقع.
4) اكتب معرف اللاعب.
5) اختر الشدات.
6) اضغط متابعة الدفع.
7) ستظهر لك طرق الدفع: البطاقة البنكية أو المحفظة الإلكترونية.

ملاحظة: هذه النسخة تضبط واجهة اختيار طرق الدفع فقط. ربط Kashier Test الفعلي يحتاج Backend لأن مفتاح Kashier السري لا يجب وضعه داخل HTML/GitHub Pages.
